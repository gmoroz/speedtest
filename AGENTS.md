# speedtest

Все команды запускай через `make`.

- `make install` подключает git hooks, дописывает локальные exclude инструментов агента (.serena, .playwright-mcp) в git info/exclude и через цели кубиков *-init-env создаёт их .env со случайными свободными хост-портами, если файла ещё нет.
- `make format` форматирует код.
- `make lint` сначала форматирует код (`make format`), затем запускает быстрые проверки всего проекта. Pre-commit через `make pre-commit-check` форматирует и линтит только кубики с файлами в индексе (или при изменении общей инфраструктуры) и падает, если форматер изменил файлы: добавь их и повтори коммит. При изменениях только markdown-файлов проверка check-jscpd пропускается, остальные проверки выполняются.
- `make test` запускает тесты.
- Перед завершением работы обязателен зелёный `make full-check`; пропущенные проверки кода он печатает явно.
- Отправляй изменения только через `make push`.
- Новое поведение и исправление бага — с тестом; баг сначала воспроизведи падающим тестом.
- Не отключай и не ослабляй тесты, lint, coverage, type checks и пороги ради зелёного результата.
- При падении `make full-check` исправляй код или тест по контракту, а не сам gate.

Инструкции слоя лежат в `AGENTS.md` его каталога (у ci — .github/AGENTS.md); перед правкой в каталоге слоя прочитай его.
